# Francis Residence

A static Three.js / WebGL walkthrough built from `FrancisProject-3DView-{3D}.fbx`. The original file remains the source of the architectural geometry. `Francis-Web.blend` is the editable prepared scene, and `public/models/francis.glb` is its browser export.

## Run

Install Node.js 22.12+ or 24+, then:

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:5173. The preview server listens only on this computer.

```sh
npm test
npm run build
npm run preview
```

## Host

Upload the **contents of `dist/`** to any static HTTPS host (Netlify, Vercel, GitHub Pages, object storage or your own web server). All geometry and textures are bundled locally. Relative asset paths support hosting in a subdirectory. No backend, API keys, or ongoing asset-service connection is required. Do not open `index.html` with `file://`; serve the build over HTTP/HTTPS.

## Scene preparation

Run `scripts/download_assets.py` with Python 3 and internet access to fetch the CC0 assets. Then run Blender in background mode:

```sh
blender --background --factory-startup --python scripts/prepare_scene.py
```

The script retains the original architectural dimensions, generates world-aligned UVs, groups meshes by level and surface class, replaces the sitting-room furniture with custom upholstered meshes, uses Poly Haven furniture in other spaces, and rebuilds four beds with beveled upholstery, mattresses, soft pillows and folded throws. Headboard sides follow the original joinery. The reference update adds shaker trim, a compact kitchen island, paneled bedroom backdrops and separate bedroom flooring. The original beds' footprints determine placement. `scripts/prepare_landscape.py` exports selected tree and shrub levels of detail; `scripts/assemble_blender.py` includes planting in the editable Blender deliverable. Run these after asset downloads, with scene preparation before final assembly. `scripts/reference-materials.json` records the default Blender finishes; keep it in sync with `src/design.js` when revising the palette. Generated beds are custom geometry, not purchased manufacturer assets.

Finishes are **reference-inspired**: the FBX contains no materials or texture assignments. `src/design.js` defines finish choices, colors and room viewpoints. Material groups are inferred from source object names, not a verified specification. The supplied exterior and kitchen/bedroom images establish the visual direction. Colors, gloss and textures are approximations from those images, not verified paint codes or measured manufacturer properties. A product finish schedule is needed for product-specific accuracy. Structural dimensions are imported rather than independently surveyed. Some BIM boxes and mechanical details remain as exported.

Doors are closed in the source; Clear doorways hides their exported geometry for walking access, and room shortcuts provide direct access. Walking handles nearby solid surfaces and small height changes, but is not a complete navigation mesh, and guided navigation uses room shortcuts. Light, Balanced and High view detail settings adjust resolution, shadow size and planting shadows. Shadow maps refresh on visibility changes rather than every frame. No baked indirect lighting is supplied; the scene uses environment lighting, directional shadows and emissive fixtures.

Asset provenance is in `public/asset-credits.json`. White marble is ambientCG Marble012 (https://ambientcg.com/a/Marble012), licensed CC0 (https://docs.ambientcg.com/license/). Poly Haven models and textures are CC0: https://polyhaven.com/license. Their public assets are freely available. The website includes a Powered by Poly Haven credit.

## Verification

`npm test` checks schedule import validation and room coordinates. `scripts/interaction_check.mjs` verifies actual walking, schedule export/import and persistence. `scripts/browser_check.mjs` uses Playwright to load the actual GLB, capture views, change and persist materials, and inspect the mobile layout. Run it with the local dev server active and Playwright Chromium installed. `scripts/reference_check.mjs` verifies independent kitchen/bedroom presets, restore/persistence and asset loads and captures the reference-inspired views. `scripts/interior_geometry_check.mjs` verifies actual exported chair support overlaps, lowered back heights, throw-cushion seat/back contact and solid walls behind each complete artwork frame. `scripts/chair_detail_check.mjs` checks the rounded chair meshes and captures fabric close-ups. `scripts/luxury_check.mjs` checks seating orientation, cabinet finishes and interior lighting and captures interior views. `scripts/marked_garden_check.mjs` verifies exact original kerb vertices and the agreed grass/paving layout. Preview images in the project root show tested views.
